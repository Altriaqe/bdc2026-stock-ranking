# BDC2026 B 阶段稳健 Top5 组合设计

## 1. 目标

在完全保留官方基准同源数据链路、离线训练要求和 Docker 复现方式的前提下，将当前容易被单只股票主导的 Top1 方案改造为可复现的稳健 Top5 组合方案。最终输出固定为 5 只不同股票、每只权重 `0.2`、总权重 `1.0`，以提高未来一周收益为第一目标，同时降低单股误判导致整次提交失效的概率。

本设计不承诺未来收益必然为正。验收依据是严格无泄漏的历史周频回测、相对当前 Top1 与官方基准的稳健性改善，以及最终训练、推理、Docker 复现和结果哈希的一致性。

## 2. 官方约束

- 数据和任务：基于沪深 300 成分股历史数据，预测从 T+1 开盘买入至 T+5 开盘卖出的组合收益。
- 输出：`result.csv` 使用 UTF-8 编码，表头为 `stock_id,weight`，最多 5 只不同股票，权重和不超过 1。
- 评分：各股票 T+1 至 T+5 开盘收益按提交权重加权求和，现金收益为 0；组合收益必须超过官方基准才有排名资格。
- 复现：固定随机种子，从训练开始重新运行后必须生成完全一致的结果。
- 资源：训练不超过 8 小时，预测不超过 5 分钟，提交镜像不超过 10GB。
- 环境：训练和预测阶段不得联网，主要贡献必须来自机器学习训练和预测。
- 数据源：继续使用官方基准同款 Baostock 日线、沪深 300 股票池和后复权口径，不增加未报备外部数据或预训练模型。

## 3. 当前问题诊断

### 3.1 Top1 放大预测误差

当前 `portfolio_size=1`，任何一次排序首位误判都会使整周收益由单只股票决定。上一阶段 `601868` 的高分来自特定评分周，不能证明该信号可跨市场状态泛化。

### 3.2 人工 overlay 对单期结果过拟合

当前生产分数为：

```text
zscore(model_score) + 0.7 * zscore(volume_ratio_20)
```

`volume_ratio_20` 已经存在于模型特征中，再次以固定权重叠加会重复放大放量信号。`0.7` 是围绕上一评分期调出的生产参数，缺少多周、跨折验证支持，因此应从生产路径移除。

### 3.3 训练评价与提交口径不一致

训练报告用 Top5 收益评价模型，生产却输出 Top1。当前 `calculate_top_k_return_metrics` 对 TopK 收益直接求和而不是按提交权重计算，无法直接代表官方组合收益；当前 walk-forward 也没有在训练与验证边界清除 T+1 至 T+5 标签重叠。

### 3.4 验证样本高度重叠

相邻交易日的五日持有期大量重叠，会把相近行情重复计入验证，夸大有效样本量。B 阶段实际上只评价一个独立周，因此模型选择应以非重叠周频模拟为主。

## 4. 文献依据

建议检索式：

- 中文：`股票横截面收益 机器学习 排序`、`组合优化 估计误差 等权`、`条件风险价值 投资组合`
- 英文：`cross-sectional stock returns machine learning tree models`、`naive diversification estimation error portfolio`、`CVaR portfolio optimization`

已通过 Crossref 核对以下文献元数据：

1. Gu, Kelly, and Xiu (2020), “Empirical Asset Pricing via Machine Learning,” *The Review of Financial Studies*, 33(5), 2223–2273, DOI `10.1093/rfs/hhaa009`。该研究在大规模资产定价比较中发现树模型和神经网络表现突出，主要收益来自对非线性预测变量交互的捕捉；主导信号包括动量、流动性和波动率。本项目继续采用 XGBoost/LightGBM 处理表格型横截面特征与此一致。
2. Kelly, Pruitt, and Su (2019), “Characteristics are Covariances: A Unified Model of Risk and Return,” *Journal of Financial Economics*, 134(3), 501–524, DOI `10.1016/j.jfineco.2019.05.001`。该研究支持把股票特征与共同风险结构共同纳入横截面收益建模，本项目据此在候选选择时加入收益相关性约束。
3. DeMiguel, Garlappi, and Uppal (2009), “Optimal Versus Naive Diversification: How Inefficient is the 1/N Portfolio Strategy?” *The Review of Financial Studies*, 22(5), 1915–1953, DOI `10.1093/rfs/hhm075`。该研究系统讨论了参数估计误差下复杂最优组合相对 `1/N` 的不稳定性。本项目仅有一次五日持有期且候选收益估计噪声很大，因此最终采用 5 只等权，而不是精细预测权重。
4. Ledoit and Wolf (2004), “A Well-Conditioned Estimator for Large-Dimensional Covariance Matrices,” *Journal of Multivariate Analysis*, 88(2), 365–411, DOI `10.1016/S0047-259X(03)00096-4`。该研究为高维协方差收缩估计提供依据。本项目使用 Ledoit-Wolf 收缩协方差或等价稳定相关估计，避免普通样本协方差在短窗口下病态。
5. Rockafellar and Uryasev (2000), “Optimization of Conditional Value-at-Risk,” *The Journal of Risk*, 2(3), 21–41, DOI `10.21314/JOR.2000.038`。该研究为使用 CVaR 衡量尾部损失提供依据。本项目在周频回测中报告下侧 CVaR，并将其作为配置选择的风险惩罚，而不只看平均收益。

## 5. 推荐架构

### 5.1 数据与标签

保持 `get_stock_data.py` 的 Baostock 数据链路、现有字段规范化和 `future_return = open(T+5) / open(T+1) - 1` 标签定义。开发回测使用当前可用历史数据；正式提交前，在 2026-07-31 收盘数据可用后重新采集到最新可见交易日，再完整训练和推理。

训练数据只包含在特征时点之后能够完整观察 T+5 标签的样本。推理始终读取最新可见历史行情，不读取未来评分周数据。

### 5.2 Purged walk-forward

新增带清除区间的 walk-forward：

- 验证区间按时间递增，禁止随机切分。
- 外层折数固定为 `4`，最初训练窗至少包含 `252` 个交易日；每个外层训练窗内再使用 `3` 折 walk-forward 选择参数。
- 每个验证折开始前清除 `future_sell_offset=5` 个交易日，确保训练样本标签窗口不与验证期重叠。
- 模型选择使用验证区间内每隔 `5` 个交易日抽取一次的非重叠周频再平衡点。
- 保留逐日验证结果用于诊断，但不得用它替代周频主结果。

### 5.3 多模型排序集成

保留三种互补模型：

- XGBoost Ranker：学习同一交易日内的相对收益排序。
- LightGBM LambdaRank：提供另一种树结构和排序损失实现。
- HistGradientBoostingRegressor：直接预测裁剪后的连续五日收益，补充排序模型无法表达的收益幅度信息。

每个模型的原始输出先转为横截面百分位秩，再集成。生产权重采用“收缩验证权重”：一半为三模型等权，一半来自各模型在 purged walk-forward 中的非负稳健得分。混合后将超过 `0.5` 的权重截断，并把超额部分按其余模型当前权重比例重新分配，直至所有权重不超过 `0.5` 且总和为 `1`。如果验证得分全部无效或非正，则自动退化为等权集成。该规则既利用验证信息，又避免当前验证加权完全追随历史赢家。

固定的 `volume_ratio_20` overlay 从生产路径删除；相关成交量特征仍由三个模型正常使用。

### 5.4 Top5 候选与相关性控制

从集成得分最高的 `15` 只股票中枚举所有 5 只组合，共 `C(15,5)=3003` 个候选，计算：

- 组合平均预测秩；
- 近 60 个交易日日收益的 Ledoit-Wolf 收缩方差；
- 平均两两相关性；
- 单只股票数据新鲜度与有效历史长度。

剔除最新交易日缺失、少于 `60` 个有效日收益或价格无效的股票。组合选择目标为：

```text
selection_score = mean_prediction_rank
                  - lambda_variance * normalized_variance
                  - lambda_correlation * normalized_mean_pairwise_correlation
```

风险系数不根据最终评分周调参。内层网格固定为 `lambda_variance ∈ {0, 0.25, 0.5, 1.0}`、`lambda_correlation ∈ {0, 0.1, 0.25, 0.5}`，并在外层折报告无偏表现。方差和平均相关性在每个横截面候选集合内转换为 `[0,1]` 百分位秩后进入目标，避免量纲影响。若协方差估计失败，确定性降级为集成排名最高的 5 只；若通过数据质量过滤的股票不足 5 只，则直接报错，不生成正式结果。所有并列按 `stock_id` 升序打破，保证复现。

### 5.5 等权输出

最终选中的 5 只股票统一输出 `weight=0.2`。不根据预测分数做 softmax，也不允许单票权重超过 `0.2`。这把模型不确定性集中在股票选择，而不让不可靠的预测幅度再次放大持仓。

## 6. 稳健模型选择与评价

### 6.1 官方口径指标

每个非重叠周频再平衡点按正式提交口径计算：

```text
portfolio_return = sum(weight_i * future_return_i)
```

Top5 等权时为五只股票收益均值。所有模型和组合参数必须按这个指标比较，不再使用未加权的 TopK 收益和。

### 6.2 稳健性指标

每个候选配置报告：

- 周平均收益和周中位数收益；
- 正收益周比例；
- 超过横截面等权基准的周比例；
- 收益标准差、10% 分位数、下侧 CVaR(10%) 和最差周收益；
- 各折平均收益及折间标准差；
- Top5 股票集合相邻周 Jaccard 稳定度；
- 相对当前 Top1、简单模型 Top5 和官方基准的差值。

内层配置选择采用统一的稳健目标：

```text
robust_score = mean_weekly_return + cvar_penalty * min(cvar_10, 0)
```

`cvar_10` 定义为该验证段最差 `ceil(10% × 周数)` 个周收益的均值。`cvar_penalty` 固定从 `{0, 0.25, 0.5, 1.0}` 中选择，并与组合风险系数一同通过内层 walk-forward 确定。外层折只评估，不参与参数选择。最终生产配置按所有外层折的中位排名确定；若中位排名相同，依次选择平均收益更高、CVaR 更高、参数惩罚更小的配置，避免单折异常行情决定方案。

### 6.3 对照实验

至少比较：

1. 当前 XGBoost + overlay + Top1；
2. XGBoost Top5 等权；
3. 三模型简单等权秩集成 + Top5 等权；
4. 三模型收缩验证权重 + 相关性约束 Top5 等权；
5. 官方基准结果或可复现的官方基准逻辑。

只有方案 4 在外层周频回测中相对方案 1 明显降低尾部损失，且平均收益不因少数异常周虚高时，才作为最终生产路径；否则退回通过外层验证的更简单方案 2 或 3。

## 7. 代码边界

预计调整以下职责，不做无关重构：

- `code/src/config.py`：增加 purged split、周频评估、候选池、风险网格和生产组合配置；默认 `portfolio_size=5`，关闭 overlay。
- `code/src/featurework.py`：修正官方权重口径指标；实现 purged split、非重叠周频抽样和确定性秩标准化。
- `code/src/portfolio.py`：新增候选过滤、收缩协方差、5 只组合枚举、风险目标和等权结果生成。
- `code/src/backtest.py`：新增周频回测、嵌套参数选择、基线比较和稳健性报告。
- `code/src/train.py`：生成折外预测，确定收缩集成权重和风险参数，并将全部生产配置写入元数据。
- `code/src/test.py`：加载三模型与组合配置，生成 Top5 等权提交；移除人工 overlay 生产分支。
- `code/src/compliance.py`：继续执行股票数量、唯一性、权重和与列名检查。
- `tests/`：新增时间切分、指标、集成、组合选择、确定性与合规测试。
- `readme.md` 和 `docs/`：记录方法、数据来源、创新点、训练推理流程、回测结果和复现证据。

## 8. 数据流

```text
Baostock 同源历史数据
  -> 字段标准化与历史可见特征
  -> T+1/T+5 标签
  -> purged walk-forward
  -> XGB Ranker / LGB Ranker / HGB Regressor
  -> 横截面秩与收缩集成
  -> Top15 候选
  -> 收缩协方差与相关性约束枚举
  -> Top5 等权组合
  -> 官方口径周频回测与稳健性报告
  -> 固化生产元数据
  -> 最新可见数据推理
  -> output/result.csv
```

## 9. 错误处理与确定性

- 所有模型、噪声增强和切分固定随机种子 `42`。
- 训练前检查日期单调性、重复 `(stock_id, trade_date)`、股票数量、最新日期和必需列。
- purged split 数量不足时直接报错，不悄悄退化为随机验证。
- 模型文件、特征列或元数据不一致时推理失败并给出具体缺失项。
- 候选股票不足 5 只时推理失败，不生成不完整正式结果。
- 协方差不可用时按确定性降级规则选择排名前5；降级原因写入报告。
- 排名和组合目标并列时以股票代码字典序打破。
- 两次完整容器运行必须产生字节完全一致的 `result.csv`，并记录 SHA-256。

## 10. 测试与验收

### 10.1 单元测试

- 标签窗口与官方 T+1/T+5 开盘公式一致。
- purged split 的任一训练标签结束日早于验证特征起始日。
- 周频再平衡点之间至少相隔 5 个交易日。
- Top5 等权收益与官方加权公式完全一致。
- 集成权重非负、和为1、单模型不超过0.5，并能确定性退化为等权。
- 组合始终包含5只不同股票，每只权重0.2。
- 高相关候选在预测秩相近时受到风险惩罚。
- 相同输入和种子重复运行得到相同股票顺序和权重。

### 10.2 回测验收

- 输出所有外层折和所有非重叠周的逐期明细，禁止只保留汇总数字。
- 对照当前 Top1、简单 Top5 和官方基准。
- 最终配置的平均收益、CVaR、最差周、胜率与折间波动必须完整披露。
- 不把 `data/test.csv` 或 B 阶段未来评分数据用于训练、模型选择或参数选择。

### 10.3 工程验收

- `pytest` 全部通过。
- 本地完整训练少于 8 小时，推理少于 5 分钟。
- `output/result.csv` 通过合规检查：5行、5个唯一代码、每行0.2、权重和1.0。
- Docker 在禁网环境从训练开始运行成功。
- 连续两次 Docker 复现结果 SHA-256 完全一致。
- Docker 镜像小于10GB。
- `readme.md` 与模型元数据准确记录模型、参数、数据口径和回测结果。
