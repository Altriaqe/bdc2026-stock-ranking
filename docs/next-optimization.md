# 下一阶段优化方向

## Top5 非等权组合

本次正式提交继续使用 5 只股票各 `0.2` 的等权配置，不修改已验证结果。

下一阶段在保持股票排序模型不变的前提下，使用 purged walk-forward 回测比较等权与非等权方案，例如按排名或经校准的预期收益分配权重。只有候选方案同时满足以下条件时才进入生产路径：

- 四折平均加权收益高于等权方案；
- 最新折收益不低于等权方案；
- 最差周和 CVaR 不恶化；
- 权重和不超过 `1.0`，单只股票不过度集中；
- Docker 完整训练与第二次离线推理结果一致。

模型原始排序分数不能直接视为预期涨幅。正式实现前需要增加分数校准和权重网格验证，防止因过拟合放大单只股票风险。
